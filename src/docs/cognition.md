# 思维篇

&emsp;&emsp;在我们发出的问卷中，有非常多优秀的建平学长学姐给出了他们关于某些“思维”的反思与见解，有些建议也使得我受益颇多。在这里，我主要希望整理并讨论他们的建议。</br>

## 一、“维”：我们如何把世界联系起来

&emsp;&emsp;首先，“思维”是什么？汉字经常以形示义，用具体之物来表达一个抽象概念，“思维”之“维”左边是绞丝旁，繁体写作“糹”，本意是丝线，其带有牵连，联系的意思，所以维强调的是将本孤立的事物相系。简单来说，思维就是把原本分散的经验、感受和观念联系起来的过程/结果。举个例子，“高考思维”背后是什么发生联结？也许是“考上名校的人往往能获得更好的工作机会”“身边成绩好的同学得到了更多认可”这样的经验和印象，也可能是一次次考试排名、老师的评价、父母的期待，以及面对分数时产生的焦虑、兴奋、失落与满足。在这些经验之上，我们又逐渐形成一些观念：好成绩意味着优秀，好的大学意味着更好的未来，一次重要考试甚至可能决定之后的人生道路。当这些经验、情绪和判断一次次相互牵连，它们便不再只是几件孤立的事情，而会组成一种具有稳定意义指向的结构：我们开始习惯用成绩解释优秀，用排名判断自己，用升学理解未来。这便是一种“思维”。</br>
&emsp;&emsp;从这个角度看，要质疑一种思维，就不能只反驳它最后呈现出来的结论，还应该重新审视构成它的那些经验和观念。</br>
&emsp;&emsp;问卷中的回答并没有把“成绩不是一切”当作一句轻飘飘的安慰。有人在第一次月考后重新审视学习的目的，有人在家庭变故中重新认识亲情与友情的分量，有人在真实交流中发现英语考试成绩并不等同于运用语言的能力，也有人在数学建模、恋爱和人际交往中发现：一个人在考场上的优势，并不能自动兑换成面对复杂生活的能力。还有人直到综评录取时才意识到，相同的分数可能因为表达、经历和选择的不同，通向完全不同的结果。</br>
&emsp;&emsp;但问卷中也有一个格外清醒的回答：“目前高考仍然起决定性作用，成绩不够好时，不好讨论成绩不重要。”我很喜欢这个回答。对于高中生而言，高考确实会影响短期内能够进入怎样的平台，脱离现实处境空谈“成绩无所谓”，既廉价，也可能是不负责任的。真正值得质疑的不是对成绩的重视，而是让成绩承担本不属于它的全部意义：用一次排名解释自己的能力，用一张录取通知书判断人生的价值，再把暂时的胜负误认为永久的判决。</br>
&emsp;&emsp;问卷中被反复质疑的，还有“往死里卷”“要抓紧每一分钟学习”和“上大学就轻松了”等观念。它们的问题不在于鼓励努力，而在于把苦难本身包装成了美德，仿佛睡得越少、日程越满、牺牲越多，就越接近成功。内卷最多只能是一种手段，绝不能成为目的；时间被安排得密不透风，也未必意味着时间得到了有效利用；大学更不是高中苦役结束后自动兑现的奖赏，而只是另一段需要自主选择和承担责任的生活。一个人如果从未想过为何学习，只是不断提高忍受痛苦的能力，那么他或许越来越能吃苦，却未必越来越会生活。</br>
&emsp;&emsp;如此，我们也许可以得到第一个关于如何完善思维的建议：质疑构成某种思维的经验/观念。从这个意义上讲，我一直认为，建平语文教育给予我最珍贵的启发之一，恰恰是把相当多的时间留给了对“问题本身的反思”。我们需要辨析概念、质疑一个看似理所当然的判断，而不是简单背下一些名人名言，再把它们填进早已准备好的答案里。</br>
&emsp;&emsp;但是事情到这里还没有结束。</br>
&emsp;&emsp;因为我们很快就会遇到另外一个更加困难的问题：即使我已经在道理上质疑了一种思维，我就真的能够摆脱它吗？</br>

## 二、“思”：为什么懂得道理，却仍然做不到？

&emsp;&emsp;不妨设想几个场景（当然这是因人而异的，如果你无法与这些发生共鸣，那么也可以回想自己是否有过类似的经历）：</br>

&emsp;&emsp;长辈语重心长地告诉你：</br>
&emsp;&emsp;“熬夜不好，熬夜伤身体。”</br>
&emsp;&emsp;你听懂了。</br>
&emsp;&emsp;但你会因此从今天开始彻底不熬夜吗？</br>

&emsp;&emsp;别人告诉你：</br>
&emsp;&emsp;“金钱不是万能的。”</br>
&emsp;&emsp;这个判断似乎没有问题。</br>
&emsp;&emsp;但你会因此不再对自己的经济状况感到焦虑吗？</br>

&emsp;&emsp;学长学姐告诉你：</br>
&emsp;&emsp;“成绩不是一切。”</br>
&emsp;&emsp;你也许完全赞同。</br>
&emsp;&emsp;可如果下一场考试真的考砸了，你会因此不感到悲伤吗？</br>
&emsp;&emsp;（如果已经上了大学，也可以把“成绩”换成“绩点”。）</br>

&emsp;&emsp;为什么我们明明懂得一个道理，却仍然无法摆脱某种感受？为什么一个判断在逻辑上已经被我们接受，却仍然没有真正成为我们的一部分？这或许需要我们进一步讨论“思”。</br>
&emsp;&emsp;《说文解字》释“思”为“从心，囟声”，思从心，在中国传统思想中，“心”往往并不只是现代语境下与“理性”相对的情绪或感性，也不仅仅指生理意义上的心脏。它更接近一个完整的心灵活动场所——认知、情感、欲望、意志和价值判断并不是彼此完全割裂的，而共同构成了一个人理解和回应世界的方式。于是，我们可以重新理解前面的困惑，当我说：“我知道成绩≠一切”，这里的“知道”有时仅仅意味着我能够在概念上接受这个命题，这些道理我都可以理解，但是这个命题是否继续进入我的生命，则又不一定，如果这种观念并未继续进入，那么我们自然无法摆脱某种状态。</br>
&emsp;&emsp;可能从这个角度讲有些玄乎，我尝试给出一种可能的解释。为什么我们即使认识到“高考思维”的局限并对其发出质疑，我们仍然无法摆脱它？其实答案很简单，因为你并没有经历过高考，今天站在高中里的你，与已经进入大学的学长学姐，事实上站在不同的位置上。一个大学生可以回头说：“这一次考试真的没那么重要。”因为他已经亲眼看到，一张曾经让自己辗转反侧的试卷，并没有决定此后所有事情，即使那场考试没有达到预期，他们后来仍然可能遇到良师益友，找到新的机会，过上属于自己的生活。</br>
&emsp;&emsp;但一个仍然生活在高中环境中的人，很难仅仅通过一句话，获得与他们完全相同的理解。</br>
&emsp;&emsp;因为他人的经验（我愿意称之为“二手经验”）可以传递一个判断，却很难完整传递一种处境，而人是生活在最真实的处境（我愿意称之为“一手体验”）中的。为什么历史会反复上演？并不是因为人类完全不吸取教训，而是因为人的生命并不只是由抽象判断构成。</br>
&emsp;&emsp;我们不是只用“头脑”活着。</br>
&emsp;&emsp;一个人的生命还包括情感、欲望、恐惧、期待、习惯以及真实发生过的经验。而改变一种根深蒂固的思维，往往也需要新的经验真正进入其中。所以，对一种思维的超越，并不总是从有意识的反思开始。很多时候，我们只是先走进了一种不同的生活：</br>
&emsp;&emsp;参加一次以前从未参加过的活动；</br>
&emsp;&emsp;认识一些和自己完全不同的人；</br>
&emsp;&emsp;认真发展一个爱好；</br>
&emsp;&emsp;经历一次失败；</br>
&emsp;&emsp;试着做一件看起来“对升学没什么用”的事情。</br>
&emsp;&emsp;这些体验不会在当下让你感觉到你在反思“唯成绩思维”，而是以一种无意识而悄无声息的方式进入你的思维，进入你的意义结构。直到某一天你回头看会发现，自己已经不再完全用原先的方式理解世界了。</br>


## 三、所谓“建平思维”

&emsp;&emsp;如果存在所谓“建平的思维”，它绝不是一种固定的形态，为什么建平的同学们更能意识到“成绩≠一切”？因为他们有权利**主动**选择参加比赛，参加社团，也可以选择外出游学，参与“930”的筹备或单纯成为参与者：选择从“唯成绩论”世界中脱出，以真实体验重新理解自己。我们能够沉浸于建平丰富的校园活动中，慢慢将所有那些原本混乱、彼此冲突的感受和经验整体理解，从而审视自己的内心。</br>
&emsp;&emsp;当然最后，我应当替这份问卷说说话，如果很多道理必须自己经历以后才能真正理解，那么这份问卷的意义是什么？为什么还要听学长学姐讲这些已经被他们经历过的事情？我认为，二手经验的真正意义不在于替你经历，而是帮助你辨认自己的经历。今天你读到一句话，你也许会觉得“有一点道理”，但一年、两年、甚至更久之后，当相似的事情真正发生在自己身上，你可能会想起：</br>
&emsp;&emsp;原来我的焦虑并不是完全无法理解。</br>
&emsp;&emsp;原来我眼前以为天大的事情，在另一个阶段可能会以不同的方式被看待。</br>
&emsp;&emsp;原来还有另一种解释。</br>
&emsp;&emsp;原来......</br>

&emsp;&emsp;以下内容以问卷为基础总结编写：</br>

### 3.1 “优秀”不是一张通用模板

&emsp;&emsp;建平并不只有一种对“优秀”的想象。成绩、理科班、竞赛奖项、学生工作、大型活动，甚至“会玩”，都可能成为某个圈子里的荣誉勋章。多元评价当然比唯成绩论更宽容，但如果你只是把“成绩好”这一个标签，换成“成绩好、竞赛强、活动多、社交广”四个标签，那么评价标准看似变多了，留给人的枷锁反而变得更重：过去只要害怕自己分数不够高，现在还要害怕自己不够有趣、不够活跃、不够“全能”。</br>
&emsp;&emsp;一个人不是等待填满的履历表。考试可以衡量你在某些知识和能力上的当下表现，却没有资格替你判决天分、品格和未来；一次获奖能证明你在某项竞争中胜出，却不能证明你比没有站上领奖台的人更值得被尊重。那些为演出搬过道具、为集体收拾过烂摊子、在朋友低谷时耐心听他说话的人，他们的价值很难被排名和奖状记录，却真实地支撑着一个集体。</br>
&emsp;&emsp;所以，不要急着问“怎样才算优秀”。这个问题很可能从一开始就问错了。更值得问的是：我想成为什么样的人？我愿意为什么付出？当掌声、排名和名头都被拿走以后，我还愿意做什么？能回答这些问题，比努力活成别人口中的“优秀学生”更重要。</br>

### 3.2 内耗源于比较

&emsp;&emsp;在优秀者密集的环境里，人很容易把别人的优势拼成一个现实中根本不存在的完美人格：要有甲的成绩、乙的竞赛奖项、丙的社交能力和丁的情绪稳定，然后用这个虚构的怪物来审判真实的自己。这不是上进，而是一场永远不可能胜利的比较。</br>
&emsp;&emsp;内耗不是因为你还不够优秀，而常常是因为你把评价自己的权力外包给了同学的目光、老师的态度、班型的名头和一张不断刷新的排名表。但别人的天分你无法复制，别人的家庭条件你无法选择，别人的精力和际遇也不会因为你更努力就自动成为你的。只有承认这些客观差异，努力才不会沦为对他人人生的徒劳模仿。</br>
&emsp;&emsp;停止内耗不等于停止进步，而是找到适合自己的前进途径。去了解自己的学科特点、水平区间、精力上限和真正在意的事；把目标写成可以行动、可以检验的事，而不是“我必须在某方面比某人更好”；和值得信任的朋友、老师交流，也给自己留下犯错和改变方向的余地。所谓“做自己”不是一句躺平宣言，而是你开始对自己有足够清醒的认识，也愿意对自己的选择负责。</br>

### 3.3 小心“假努力”

&emsp;&emsp;问卷中有人质疑刷题、错题本、竞赛班、科创课题，也有人反思自己曾经对理科班和某些评优过度执着。但刷题、整理错题、参加竞赛本身都没有原罪。真正低效的，是不问目标、不看反馈、不做取舍，只用疲惫程度证明自己已经尽力。</br>
&emsp;&emsp;最危险的“假努力”并不是偷懒，而是它能让你忙到没有时间怀疑方向。你可以每天睡得很少、把日程填得很满、参加所有看起来有含金量的活动，然后在筋疲力尽中获得一种悲壮的安全感。可痛苦从来不是成长的来源，繁忙也不是价值的证明。如果一种方法长期没有产生可观察的改善，就应该调整；如果一项活动既不服务于你的目标，也不能给你带来真实的收获和经验，就不必去做。</br>
&emsp;&emsp;即使一件事确实能换来奖项、综评、头衔、升学优势或他人的认可，也不意味着它真正促进了你的成长。这与前面“无效果”的假努力不同，且更难识别，也更加值得警惕。单纯的“拒绝荣誉”在强调奖项、成果的现今环境看，似乎有些过激，但我们也必须警惕荣誉反过来操纵我们的思维和选择。</br>
&emsp;&emsp;荣誉体系不仅奖励行为，还会悄悄改变人的欲望。一个人最初可能只是喜欢研究、表演或组织活动，后来却开始只关心名次、头衔和履历；一旦没有可兑换的结果，就认为事情“不值得”。**最需要警惕的，不是你没有得到荣誉，而是荣誉逐渐替你决定了什么值得热爱。**</br>
&emsp;&emsp;真正的自律，不是什么都咬牙坚持，不是让沉没成本逼迫自己，也不是让荣誉和利益替自己决定什么值得追求，而是始终知道自己为何出发。</br>

### 3.4 失败不会自动使人成长

&emsp;&emsp;分班失利、春考或高考不如预期、竞赛和评优落选、向喜欢的人表白被拒绝——问卷里记录的失败彼此不同，但它们共同戳破了一个幼稚而顽固的幻觉：只要我足够努力、足够聪明、提前做好规划，世界就应当按我的剧本运行。</br>
&emsp;&emsp;世界从不签署这样的合同。努力会提高成功的可能，却无法提供必然成功的保证；优势科目可能失手，令人羡慕的班型未必提供适合你的环境，一份曾经志在必得的荣誉在几年后可能毫无分量。承认这些不确定，不是劝人消极，而是让我们终于能把力气用在可控的事情上：调整方法、建立短期目标、修复关系、承担后果，然后继续生活。</br>
&emsp;&emsp;但也不要浪漫化失败。失败本身不会自动带来智慧，它或许让人更清醒，也可能只让人更怨恨。真正有价值的不是“我曾经失败”，而是“失败迫使我放弃了哪个错误判断，又建立了什么新的行动方式”。如果吃了苦却不反思，苦就只是苦；如果摔倒之后只是急着证明自己没错，那么同一块石头还会在前面等你。</br>

### 3.5 真正能带走的东西

&emsp;&emsp;当受访者回头看建平三年，他们反复提到的并不是某道题、某张奖状或某次排名，而是自学、沟通、组织、合作、多线并行和与不同的人相处的能力。竞赛、模联、志愿活动、班级工作和“930”的价值，不只在于它们能不能写进综评，而在于你是否真正地做过事、遇到过人、解决过问题，也在于你是否在这些经历中发现了自己的热爱与边界。</br>
&emsp;&emsp;“发展得好”也不应只有一种译法。它可以是进入理想的大学，也可以是找到真正愿意学习的专业；可以是在更大的舞台上被看见，也可以是终于不再依靠别人的目光确认自己。一个人每天过得开心，学习尚可，爱好不断生长，身边有几个能够真诚交谈的人，这样的生活并不比任何光鲜的模板更低级。</br>
&emsp;&emsp;高中不是一间只生产大学录取通知书的工厂。如果三年以后，你只学会了在有标准答案时得分，却不知道如何选择、如何与人合作、如何面对失败、如何安顿自己，那么即使成绩单十分漂亮，这场教育也很难说已经完成。反过来，如果你逐渐知道自己是谁、想去哪里、愿意为何事承担代价，那么你就已经从这三年里带走了比一串数字更持久的东西。</br>

## 结语
&emsp;&emsp;正如杜威所说：“教育是生活的过程，而不是为未来生活所作的准备。”愿每一个建平人，都能在丰富的生活中自由生长，在真实的经验中慢慢成为自己。</br>

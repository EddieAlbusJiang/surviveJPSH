# 升学篇

&emsp;&emsp;从高中走向大学，是一件复杂的事，可以说非常多的同学会将升学认为是高中学段的主要目的。而我们真正深刻地意识到升学不只是关于高考成绩这件事，却很可能是在高考后的那一个月，当我们开始研究志愿，发现多元升学的不同路径时，却为时已晚。因此本篇升学篇旨在解决作为一个独立自主的个人，如何优雅地布局和选择自己的升学路径，不让自己高考后度过狼狈的一个月，抑或是度过狼狈的大学四年。</br>
&emsp;&emsp;**免责声明**：请注意，本篇内容将不涉及升学方法指导、升学客观事实，将只涉及opinion，请读者自辩真伪，理性采信。了解升学真实资讯，请查阅上海市教育考试院和各校招生简章，一切内容以当年官方发布的文件为准。本篇作者不为内容真实性负责。</br>

## 一、升学路径
&emsp;&emsp;高三同学在选择升学路径时（如强基计划、综合评价、普通批裸分、出国），往往容易只关注是否能“低分高报”，而忽视了不同路径背后的具体要求与后续影响。而其中部分升学路径（强基计划、综合评价、出境多元升学、中外合办、特殊类型招生）则需要在高一高二提前谋划，而不是考完之后，看着和自己同分数段的同学去了上科大、纽大、南科大、华工、港三新二、港中深、港科广，自己却盯着志愿表叹气。</br>

### 强基计划
&emsp;&emsp;先来谈强基计划。在这里不赘述强基计划是什么，这个请大家参见各校简章，只谈谈进入大学后强基计划的真实体验。首先，对于上海考生报考复旦和交大的强基计划而言，降分力度可以说不大（物化生文史哲），即能通过强基计划过五关斩六将的学生，他的分数基本是达到了复交综评线的，不太会出现外省市报考复交综评一样可能出现捡漏的情况。其次，先来说理科，理科强基计划素来是竞赛生的天堂，如果没有接触过一点竞赛，完全是课内按部就班走的，强基只怕是校测笔试就被刷了。笔者身边通过强基计划进入复交理科专业的同学，基本是在建平就属于是某一个理科特别强，至少有省二的学生。</br>
&emsp;&emsp;然后说复交的文科强基。文科强基固定是三个专业，即历史、古文字和哲学。从入学门槛上，文科强基不像理科强基一样，有很严肃的竞赛门槛，然而其对于文科的直觉的看重是非常之显著，在这一点上，复旦的文科强基很像综评。</br>
&emsp;&emsp;最后说复交强基的优势，强基的最大优势就是可以转段直研，按部就班的走基本能读到博士。选择强基路径的学生一般而言都是对基础学科有自己的理解，很坚定地去选择。如果只是想低分捡漏，那在复交强基不太可能出现，且由于强基在转专业上存在限制，就算捡漏，读起来也是非常的难受。且强基计划的本科课程一般都会安排荣誉课（即高难度课程），可能导致本科绩点不够突出，若后续想申请国外名校读研，偏低成绩单会构成不利因素。同时，硕博阶段的科研指标与学术工作强度较高。</br>

### 综合评价
&emsp;&emsp;第二谈综合评价招生。综评是大部分上海考生进入复交的方式，在这里涉及很多博弈，高分段考生需要注意在这个阶段是否需要接受调剂的博弈。接受调剂意味着高分段考生大概率能录取，然而可能会因为面试成绩不佳被调剂到不喜欢的专业，而高分本身的优势可能会在普通批进入更好的专业。中档分段考生面临着潜在进入密院，或是进入电院后分流不占优势进入不喜欢专业的可能（专指交大），而低分段考生则面临着冲一冲复交普通专业，先进大门的可能。</br>
&emsp;&emsp;讲综评，最核心的部分就是面试。具体的面试方法，各校不同，参考交大附中每年发的面试案例汇总和小红书的面经，这里不赘述。对于科创、竞赛、学生活动、课内成绩，有的人说有用，有的人说没用，但到底有用没用，其实只取决于你碰到的面试官觉得有没有用，所以，我的建议是，如果你真的很喜欢这些活动，请你坚定且不带杂念的去做，既不必找理由说“我在准备综评”而逃避课内学习，也不必非常功利的充值一个科创、竞赛、课题，这也显得很蠢，而且实际上面试官一眼就能看穿。</br>

### 普通批次
&emsp;&emsp;第三谈普通批。讲到普通批，一般面临几大博弈，一是留上海还是出上海的博弈，二是保学校还是保专业的博弈，三是大类招生还是承诺专业的博弈，四是承诺保研与无承诺的博弈。用经济学的语言来讲，这四样内容构成了你的效用函数，而分数是你的约束条件，你要做的不过是在约束条件下最大化你的个人效用。</br>
&emsp;&emsp;上述问题均无标准答案，有的人很在乎自己在哪里读书，能不能走读；有的人在乎大门，因为单位招聘会直接卡死985/211的门槛，有的人在乎小门，因为土木、部分文科的就业确实是相对糟糕；有的人相信自己在大学里能卷到好专业，敢搏大类招生、保研，有的人想躺平，稳稳地保专业、保研。这些观点全都没有错，关键是在你填报志愿的时候，你需要亲历亲为地了解学校，并且了解你自己。你需要问自己：你真的喜欢这个专业嘛？你真的能接受离沪很远上学吗？你真的能和外地考生一样卷三年拿到保研资格吗？如果拿不到，你是选择本科就业？还是选择境外升学？你不仅需要借鉴别人的看法，更多的则是，你要问问你自己，作为一个独立的个体，你是想过一个狼狈的大学生活，还是一个有所准备的优雅从容的大学生活。</br>

## 二、选择专业
&emsp;&emsp;在这里罗列一些大家对自己专业的看法：
### 电子信息
&emsp;&emsp;想象差距倒是不大，但是确实高估了专业处境。</br>
&emsp;&emsp;这就是纯工科，偏硬件方向，适合喜欢动手的同学、以及对工程物理有兴趣的同学（专业涉及大量物理）。如果是数学物理基础薄弱，也能学，但是会稍微多费点劲。专业虽处境远好过化学、生物、土木、机械等，但是和计算机、自动化、人工智能等仍有明显差距，可以勉强作为保底选择。专业目前也同样会面对ai冲击，并非不受ai影响，但是我相信在ai时代，硬件工程师仍能占有一席之地。</br>
### 中（医）药
&emsp;&emsp;药学学化学、生物、药理、药剂、药分，中药多点中药的内容。想赚快钱的别来。现在环境不好，你最好有一个宁受污名也救一人的心，特别是临床医学。我是没这个决心所以没选临床。其他医学相关专业也最好要有，就算赚不到大钱也要为医疗卫生。“凡大医治病，必当安神定志，无欲无求，先发大慈恻隐之心，誓愿普救含灵之苦。”孙思邈《大医精诚》。这篇短文的心态是一个医疗专业从业者该有的。</br>
### 汉语言
&emsp;&emsp;选点汉语言历史这种专业牺牲的就只有未来。都说就业选择窄和到时候考研考公考编压力会比较大，他们说的一点都对。不过如果目标比较清晰然后学的进去的其实也还好。高中小三门学的来的话高三其实没付出什么还可能可以轻松一点，毕竟政史地这种背过了就是背过了还有多点时间去搞大三门。而且文科上了大学课会比较少。至少我的课比隔壁哲学的少，哲学比新传的少，然后都比理工少的多。我是真见过别的专业周一到周五早八晚十课表接着上高中的。（完全先甜后苦不是推荐）</br>

## 结语
&emsp;&emsp;升学路径和专业的选择并非简单的“高分与低分”问题，而是不同培养模式与未来发展的权衡。了解各条路径的真实运行机制与潜在代价，能够帮助高三同学在高考志愿填报时做出符合自身定位的决策，理智、自主地规划后续的大学生活。 </br>

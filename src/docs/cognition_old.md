# 思维篇

&emsp;&emsp;在我们发出的问卷中，有非常多优秀的建平学长学姐们给出了他们关于某些“思维”的反思与见解，有些建议也使得我受益颇多。在这里，我主要希望客观呈现他们的建议，当然也想分享一些围绕如何完善“思维”的碎片思考。</br>

## 一、“维”：我们如何把世界联系起来

&emsp;&emsp;首先，“思维”是什么？汉字经常以形示义，用具体之物来表达一个抽象概念，“思维”之“维”左边是绞丝旁，繁体写作“糹”，本意是丝线，其带有牵连，联系的意思，所以维强调的是将本孤立的事物相系，简单来说，思维就是把原本分散的经验、感受和观念联系起来的过程/结果，举个例子，“高考思维”背后是什么发生联结？也许是“考上名校的人往往能获得更好的工作机会”“身边成绩好的同学得到了更多认可”这样的经验和印象，也可能是一次次考试排名、老师的评价、父母的期待，以及面对分数时产生的焦虑、兴奋、失落与满足。在这些经验之上，我们又逐渐形成一些观念：好成绩意味着优秀，好的大学意味着更好的未来，一次重要考试甚至可能决定之后的人生道路。当这些经验、情绪和判断一次次相互牵连，它们便不再只是几件孤立的事情，而会组成一种具有稳定意义指向的结构：我们开始习惯用成绩解释优秀，用排名判断自己，用升学理解未来。这便是一种“思维”。</br>
&emsp;&emsp;从这个角度看，要质疑一种思维，就不能只反驳它最后呈现出来的结论，还应该重新审视构成它的那些经验和观念。</br>
&emsp;&emsp;在问卷中，许多学长学姐正是如此做的：</br>

### 问：第一次意识到“成绩≠一切的一瞬”：
- 高一第一次月考后，审视学习目的、重视人际交往
- 家庭变故（父母去世），发现亲情、友情、爱情比成绩更重要
- 出国旅游发现英语考试与实际交流脱节
- 成绩好但脱单没用
- 参加数学建模，一晚上没学会Matlab
- 成绩不够好时努力上进，找优秀同学问问题遭遇冷漠
- 有同学直言“目前高考起决定性作用，成绩不够好时不好讨论”
- 综评时发现同分的同学通过面试加分进了远好于自己的专业——第一次意识到成绩不等于一切

### 问：被明确认为过时的观念：（部分）
- “往死里卷”：美化苦难，卷只是途径不是工具
- “上大学就轻松了”（多人提到）
- “要抓紧每一分钟学习”

&emsp;&emsp;其中当然也有同学现实地指出“目前高考仍然起决定性作用，成绩不够好时不好讨论成绩不重要。”我很喜欢这个回答。因为质疑“唯成绩思维”，并不意味着否认成绩的重要性。对于一个高中生而言，成绩当然重要，高考当然重要。真正值得质疑的应当是：我们是否需要让成绩承担本不属于它的全部意义。</br>
&emsp;&emsp;如此，我们也许可以得到第一个关于如何完善思维的建议：质疑构成某种思维的经验/观念。从这个意义上讲，我一直认为，建平给予我最珍贵的语文教育之一，恰恰是把相当多的时间留给了对“问题本身的反思”。我们需要辨析概念、质疑一个看似理所当然的判断，而不是简单背下一些名人名言，再把它们填进早已准备好的答案里。</br>
&emsp;&emsp;但是事情到这里还没有结束。</br>
&emsp;&emsp;因为我们很快就会遇到另外一个更加困难的问题：即使我已经在道理上质疑了一种思维，我就真的能够摆脱它吗？</br>

## 二、“思”：为什么懂得道理，却仍然做不到？

&emsp;&emsp;不妨设想几个场景（当然这是因人而异的，如果你无法与这些发生共鸣，那么思考思考类似的）：</br>

&emsp;&emsp;长辈语重心长地告诉你：</br>
&emsp;&emsp;“熬夜不好，熬夜伤身体。”</br>
&emsp;&emsp;你听懂了。</br>
&emsp;&emsp;但你会因此从今天开始彻底不熬夜吗？</br>

&emsp;&emsp;别人告诉你：</br>
&emsp;&emsp;“金钱不是万能的。”</br>
&emsp;&emsp;这个判断似乎没有问题。</br>
&emsp;&emsp;但你会因此不再对自己的经济状况感到焦虑吗？</br>

&emsp;&emsp;学长学姐告诉你：</br>
&emsp;&emsp;“成绩不是一切。”</br>
&emsp;&emsp;你也许完全赞同。</br>
&emsp;&emsp;可如果下一场考试真的考砸了，你会因此不感到悲伤吗？</br>
&emsp;&emsp;（如果已经上了大学，也可以把“成绩”换成“绩点”。）</br>

&emsp;&emsp;为什么我们明明懂得一个道理，却仍然无法摆脱某种感受？为什么一个判断在逻辑上已经被我们接受，却仍然没有真正成为我们的一部分？这或许需要我们进一步讨论“思”。</br>
&emsp;&emsp;《说文解字》释“思”为“从心，囟声”，思从心（囟就是头脑），在中国传统思想中，“心”往往并不只是现代语境下与“理性”相对的情绪或感性，也不仅仅指生理意义上的心脏。它更接近一个完整的心灵活动场所——认知、情感、欲望、意志和价值判断并不是彼此完全割裂的，而共同构成了一个人理解和回应世界的方式。于是，我们可以重新理解前面的困惑，当我说：“我知道成绩≠一切”，这里的“知道”有时仅仅意味着我能够在概念上接受这个命题，这些道理我都可以理解，但是这个命题是否继续进入我的生命，则又不一定，如果这种观念并未继续进入，那么我们自然无法摆脱某种状态。</br>
&emsp;&emsp;可能从这个角度讲可能有些玄乎，我尝试给出一种可能的解释。为什么我们即使认识到“高考思维”的局限并对其发出质疑，我们仍然无法摆脱它？其实答案很简单，因为你并没有经历过高考，今天站在高中里的你，与已经进入大学的学长学姐，事实上站在不同的位置上。一个大学生可以回头说：“这一次考试真的没那么重要。”因为他已经亲眼看到，一张曾经让自己辗转反侧的试卷，并没有决定此后所有事情，他们因此遇到良师益友，因此过上了不错的生活。</br>
&emsp;&emsp;但一个仍然生活在高中环境中的人，很难仅仅通过一句话，获得与他们完全相同的理解。</br>
&emsp;&emsp;因为他人的经验（我愿意称之为“二手经验”）可以传递一个判断，却很难完整传递一种处境，而人是生活在最真实的处境（我愿意称之为“一手体验”）中的。为什么历史会反复上演？并不是因为人类完全不吸取教训，而是因为人的生命并不只是由抽象判断构成。</br>
&emsp;&emsp;我们不是只用“头脑”活着。</br>
&emsp;&emsp;一个人的生命还包括情感、欲望、恐惧、期待、习惯以及真实发生过的经验。而改变一种根深蒂固的思维，往往也需要新的经验真正进入其中。所以，对一种思维的超越，并不总是从有意识的反思开始。很多时候，我们只是先走进了一种不同的生活：</br>
&emsp;&emsp;参加一次以前从未参加过的活动；</br>
&emsp;&emsp;认识一些和自己完全不同的人；</br>
&emsp;&emsp;认真发展一个爱好；</br>
&emsp;&emsp;经历一次失败；</br>
&emsp;&emsp;试着做一件看起来“对升学没什么用”的事情。</br>
&emsp;&emsp;这些体验不会在当下让你感觉到你在反思“唯成绩思维”，而是以一种无意识的，悄无声息的方式进入你的思维，进入你的意义结构。直到某一天你回头看会发现，自己已经不再完全用原先的方式理解世界了。</br>


## 三、所谓“建平思维”

&emsp;&emsp;如果存在所谓“建平的思维”，它绝不是一种固定的形态，为什么建平的同学们更能意识到“成绩≠一切”？因为他们可以选择参加比赛，参加社团，可以选择出国旅游，可以选择930，选择将自己不浸泡在完全的成绩世界中，以一种具体的生命体验，去完成对于一种思维的反思与质疑。我们大多都无意识地进入这种生活，并在这种生活中慢慢想得明白，在这种生活中将将所有那些原本混乱、彼此冲突的感受和经验，在我们的内心获得一个可以理解的位置，安顿自己的内心。</br>
&emsp;&emsp;当然最后，我应当替这份问卷说说话，如果很多道理必须自己经历以后才能真正理解，那么这份问卷的意义是什么？为什么还要听学长学姐讲这些已经被他们经历过的事情？我认为，二手经验的真正意义不在于替你经历，而是帮助你辨认自己的经历。今天你都到一句话，你也许会觉得“有一点道理”，但一年、两年、甚至更久之后，当相似的事情真正发生在自己身上，你可能会想起：</br>
&emsp;&emsp;原来我的焦虑并不是完全无法理解。</br>
&emsp;&emsp;原来我眼前以为天大的事情，在另一个阶段可能会以不同的方式被看待。</br>
&emsp;&emsp;原来还有另一种解释。</br>
&emsp;&emsp;原来......</br>

&emsp;&emsp;所以，我将所有答案放在了这里，他们不是答案，甚至很多都存在冲突矛盾，但他们承载着饱满的生命体验与态度：</br>

### 问：被认为醍醐灌顶/值得一听的：
* 不要用学业表达对老师的反对
* 别人不可控，把自己的事调整好
* 写日记，回头看曾经觉得完蛋的事其实不算什么
* “有困难的，但也有办法、有希望”
* 不能被老师、同学、课业牵着鼻子走
* 不要做不必要的事，无论规则是否要求

### 问：对建平“优秀”标准的讨论
* 学科竞赛获奖（五大奥赛）被视为“校内荣誉”，但被指出市里竞争力有限，形成“错位的荣誉感”
* 理创班、小理科班的同学容易被看作优秀
* 成绩好＋活动多＋竞赛＋学生工作
* 直接回答“成绩好的同学”——不合理，它奖励了学习上的进步而忽略了其他所有方面
* （有同学认为建平不会⽤单⼀指标定义优秀，⿎励多⽅⾯发展）
* “会玩的人”容易被视为优秀
* 忽略了智商因素、精力有限、个人价值追求、人生思考
* 有人反思：高三后期才发现之前忽视了为大型活动出力的人

### 问：如何调整内耗问题？
* 接触同学，交流中学习优点，慢慢形成自己的标准，“不够优秀就算了”（做好自己就行）
* 和朋友聊，同龄人其实没有固定优秀模板
* “每天很开心，学得不错，爱好有发展，走到哪里算哪里”，不关心所谓优秀也可以过得很好
* 取法其上、取乎其中；和自己比较
* 找老师聊内耗，老师用弹簧弹性限度说“允许自己犯错”
* 通过观察和尝试发现自己的学科特性、水平区间
* 结论：专注自己的特质，以自己的天分、水平、精力定位方向
* 表面认同他人标准，心里自己构建目标

### 问：哪些是可能的低效努力？
* 起太早、睡太少——清醒的脑子更好用
* 啥竞赛班都参加，累且没用（对于学有余力的同学推荐化竞物竞，有一定帮助）
* 刷题效率低，不如学思维方法
* 信息学竞赛（个人情况），课程给了努力错觉但无进展
* 一心追求理科班，内耗严重
* 拼命补数理化，忽略弱势的语文、英语、生物
* 基础知识不足时做科创课题——表面工作、包装
* 错题本（尤其数理）作用不大
* 认真听副科（指在某些副科上投入过多精力而收益低）（尤其是不选的小三门）
* 过度在意与高考题型不符的有效作业题（功利主义角度）

### 问：哪些是有价值的失败并且改变了你的判断方式？
* 盲目表白被拒
* 认为物理高枕无忧（提前学完大学内容），结果任何轻视都有后果
* 春考爆炸——不要提前给自己设目标
* 对理科班师资的误判，不要太依赖外部环境
* 高三下高考失败（缺乏自律），之后改用短期目标驱动学习
* 高二分班失败，提前感受中高考失利状态，但后来没陷入高考结果的内耗
* 英语竞赛和先进个人评选——结论是“垃圾竞赛和评优经历屁用没有，不如发展爱好或补全短板”

### 问：被低估但发展好的同学的特点
* 家里有点实力（？
* 平时成绩稳定、踏实
* 心态好（踢球被抓屡次再犯）
* 努力上进、热爱生活、积极进取
* 有自己的热爱与方向，抗挫折，保持良好心态，健康，擅长沟通
* 有同学自述：曾经被人看不起，但大学生活开心充实
* 不认为每次考试的成绩可以代表一个人的能力和水平；“发展很好”绝不只是考上某所院校，可能是在大学找到自洽的学习途径或爱好的专业，或在更大舞台上展现自我价值

### 问：建平三年最有帮助的能⼒（对⼤学⽣活/⼯作）
* 社交能力、人际沟通能力
* 会玩，每天过得开心
* 组织工作（班委、声部长、930演出）——培养多线并行能力
* 自学能力
* 抱着“去学习”或“去玩”心态参加竞赛、课题活动
* 建平的个性化——让人保持动力和专注
* 低调、不轻易暴露目标
* 参与志愿者和课题项目丰富社会经验
* 自主学习能力以及沟通、跨文化沟通
* 加入模联，写各类文件的经历和大学时期的大作业相通

## 结语
&emsp;&emsp;正如杜威所说：“教育是生活的过程，而不是为未来生活所作的准备。”愿每一个建平人，都能在丰富的生活中自由生长，在真实的经验中慢慢成为自己。</br>
